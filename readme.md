欢迎来到阿敏

## 项目简介

阿敏（Mint_Digit）是一个基于 QQ/NapCat 的智能群聊/私聊机器人，当前版本实现了基本的消息响应功能。

## 整体架构

项目采用清晰的分层架构设计，各层职责明确，依赖关系单向。

### 分层架构说明

```
┌─────────────────────────────────────────────────────────────┐
│  应用层 (Application Layer)                                   │
│  napcat_logger.py - FastAPI HTTP 服务入口                    │
└────────────────────┬────────────────────────────────────────┘
                     │ 调用
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  业务逻辑层 (Business Logic Layer)                            │
│  dispatcher.py - 事件分发器                                   │
│  strategies_basic.py - 事件处理策略                           │
└────────────────────┬────────────────────────────────────────┘
                     │ 调用
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  领域模型层 (Domain Model Layer)                              │
│  events.py - Event 和 BotReply 数据结构                       │
└────────────────────┬────────────────────────────────────────┘
                     │ 调用
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  应用协调层 (Application Coordination Layer)                  │
│  message_sender.py - 消息发送协调器                           │
└────────────────────┬────────────────────────────────────────┘
                     │ 调用
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  适配器层 (Adapter Layer)                                     │
│  napcat_adapter.py - NapCat 原始事件 → 内部 Event 转换       │
│  napcat_client.py - 通过 NapCat 发送消息                      │
└──────────────────────────────────────────────────────────────┘
```

### 各层职责

1. **应用层 (Application Layer)**
   - `napcat_logger.py`：基于 FastAPI 的 HTTP 服务入口，监听来自 NapCat 的事件回调，接收请求后调用业务逻辑层进行处理，最后处理响应。

2. **业务逻辑层 (Business Logic Layer)**
   - `dispatcher.py`：事件分发器，根据事件类型和是否 @阿敏 选择不同的处理策略。
   - `strategies_basic.py`：实现具体的事件处理策略。

3. **领域模型层 (Domain Model Layer)**
   - `events.py`：定义核心数据结构 `Event` 和 `BotReply`，作为各层之间的数据交换契约。

4. **应用协调层 (Application Coordination Layer)**
   - `message_sender.py`：消息发送协调器，封装消息发送的逻辑，让应用层不需要直接依赖适配器层。

5. **适配器层 (Adapter Layer)**
   - `napcat_adapter.py`：将 NapCat(OneBot) 的原始上报 JSON 转换为内部 `Event` 对象。
   - `napcat_client.py`：封装通过 NapCat 发送消息的 API 调用。

### 分层原则

- 上层依赖下层，下层不依赖上层
- 层间通过明确的接口/数据结构交互
- 适配器层负责与外部系统（NapCat）的交互，内部业务逻辑不直接依赖外部系统

### 测试与工具

- `test/` 目录：包含针对核心模块的单元测试，有助于保证行为稳定。
- `v1/` 目录：旧版本代码，包含更多功能如用户管理、资产管理、多模型能力等。

## 数据与配置

- **配置与环境变量**
  - `NAPCAT_BASE_URL`：NapCat OneBot HTTP 服务端地址，默认值为 `http://127.0.0.1:3000`

## 运行与依赖

### 依赖

项目依赖已在 `requirements.txt` 文件中定义：

- Web 框架相关：
  - `fastapi`
  - `uvicorn`
- 其他：
  - `requests`

### 运行方式

1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

2. 启动服务：
   ```bash
   python napcat_logger.py
   ```

3. 配置 NapCat：
   - 在 NapCat 的 `onebot11.json` 配置文件中，将 `httpClients.url` 设置为：
     ```
     http://127.0.0.1:8081/
     ```
   - 确保 `enable` 设置为 `true`

## 当前功能

- **私聊处理**：当收到私聊消息时，机器人会回复"你好"
- **群聊@处理**：当在群聊中@阿敏时，机器人会回复"不好"
- **事件日志**：在控制台打印收到的事件和回复信息
- **健康检查**：提供 `/ping` 接口用于测试服务状态

## 版本说明

- **当前版本**：基于 NapCat 的简化版本，实现了基本的消息响应功能
- **v1 版本**：包含更多高级功能，如用户管理、资产管理、多模型能力封装等（位于 `v1/` 目录）
